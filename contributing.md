# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](https://github.com/sindresorhus/awesome/blob/main/code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Adding an entry

- The project must be about decision models: models that return typed decisions (choice, score, yes/no) with probabilities instead of generated text, or tools, integrations and research built on them.
- The link must work and the project must be public and usable. No placeholders, waitlists or empty repos.
- One entry per pull request, added to the bottom of the most fitting section.
- Use the format `- [Name](link) - Description.` The description is short, neutral and ends with a period. No marketing words ("blazing", "revolutionary"), no star counts.
- Check your spelling and that the entry isn't already listed.

## Updating or removing an entry

Open a pull request or issue if a link is dead, a project was renamed, or an entry is no longer maintained.
